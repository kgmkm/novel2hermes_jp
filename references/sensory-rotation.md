# 五感ローテーション

LLM の文体は視覚偏重に陥りやすい。人間の体験は五感の総合であり、視覚だけでは読者の身体感覚に届かない。各シーンで視覚以外の感覚を **2つ以上** 使うことを意識する。

## 五感一覧

| 感覚 | 小説での使いどころ | 効果 | 例 |
|------|-------------------|------|-----|
| 視覚 | 基本。すべてのシーンの土台 | 情報の中核 | 夕闇、朱い焔、白磁の肌 |
| 聴覚 | 静寂・喧騒・声の質 | 空間の奥行きと緊張 | 蝉の声、衣擦れ、足音の有無 |
| 触覚・温度 | 身体接触・気候・質感 | 読者の皮膚に直接訴える | 冷たい手、湿った空気、茣蓙の硬さ |
| 嗅覚 | 場所・季節・記憶の喚起 | 最も原始的な感情に直結 | 苔の匂い、夏草、血の鉄臭さ |
| 味覚 | 飲食・比喩として | 親密さと生々しさ | 甘い果実、苦い薬 |

## 使い方

1. シーンを書いた後、使った感覚を数える
2. 視覚以外が 0〜1 個なら、不足している感覚を 1〜2 行追加する
3. ただし説明的にならないこと。「風が冷たかった」ではなく「風が頬を切った」のように動作や比喩で示す

## シーンタイプ別推奨感覚

| シーン | 優先する感覚 |
|--------|-------------|
| 出会い・対話 | 聴覚（声） + 視覚（表情） |
| 静寂・孤独 | 聴覚（沈黙の質） + 触覚（空気の感触） |
| 自然・屋外 | 嗅覚（土・草・花） + 触覚（風・陽射し） |
| 戦闘・緊張 | 聴覚（衝突音） + 触覚（衝撃・痛み） |
| 回想・感情 | 嗅覚（記憶喚起） + 触覚（体温） |

## 避けること

- すべての感覚を詰め込まない（1シーン3つまで。説明的になる）
- 「〜の匂いがした」「〜の音が聞こえた」のような報告文体にしない
- 視覚を完全に抜かない（読者は見失う）
