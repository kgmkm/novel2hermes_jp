# キャラクター詳細仕様書テンプレート

キャラクターこそが作品ひいてはIPの中心です。この仕様書の解像度が、小説の質と画像生成の安定性を直接決定します。小説執筆時はシナリオ状況に対してキャラクターの方から行動指針が生まれ自然な台詞回しや行動につながり、画像生成時は複数生成してもキャラクターの一貫性が保たれNG画像が激減します。仕様が曖昧なキャラクターは書くたびに性格がブレ、生成するたびに顔が変わります。

各キャラクターにつき、以下の全項目を埋めます。決められない項目は、それが「読者に謎として提示される要素」「伏線として控える要素」「連載中につき後に決める方が良い要素」など事由を明記します。

## A. 基本情報

| 項目 | 内容 |
|------|------|
| 氏名（ふりがな） | |
| 性別 | 男性/女性/その他 |
| 種族 | 人間（デフォルト）/妖/獣人/精霊/神 など。ファンタジー作品では必須 |
| 年齢 / 外見年齢 | 実年齢と見た目の年齢が異なる場合は両方 |
| 誕生日 | 可能なら設定。伏線（年齢・誕生日イベント）やIP展開時に有用。決まらない場合は「不明」でよい |
| 身長 | cmまたはft。世界設定オリジナルの単位などは避ける |
| 体格・体型 | 痩身/標準/筋肉質/豊満 など + 具体的サイズ感 |
| 所属・職業・立場 | 世界観からこのキャラクターの属する社会を決める。特に無ければ無職でもOK |
| 作中での役割 | 主人公/ヒロイン/敵役/メンター/師匠/狂言回し など |

## B. 外見（画像生成AI連携の最重要項目）

画像生成 AI で安定したキャラクター再現を行うには、首から上の全要素の指定が決定的に重要です。顔のパーツ配置がブレると同じキャラクターと認識されなくなります。

| 項目 | 内容 | 画像生成タグ |
|------|------|-------------|
| 肌 | 色味（色白/小麦色/褐色）、質感（陶器/マット/艶あり）、特徴（そばかす/傷跡/痣） | |
| 前髪 | スタイル（ぱっつん/センターパート/サイドパート/M字/眉上/目にかかる など）、長さ、ボリューム | |
| 後ろ髪 | 長さ（ショート/ボブ/セミロング/ロング/腰まで/腿まで）、スタイル（ストレート/ウェーブ/ツインテール/ポニーテール/お団子 など）、ボリューム | |
| 髪色 | ベース色 + グラデーション/メッシュの有無と色（可能ならカラーコード） | |
| 瞳の色 | 虹彩の色 + 瞳孔の形状/色（可能ならカラーコード） | |
| 瞳の形 | 丸目/垂れ目/ツリ目/ジト目/細目/大きさ（大中小） | |
| 睫毛・眉 | 長さ・太さ・形・位置 | |

以下はキャラクター設定を鑑みて有無を検討してください。キャラクターの無個性化を避けるため2項目以上は必ず設定します。

| 項目 | 内容 | 画像生成タグ |
|------|------|-------------|
| 髪アクセサリ | リボン/カチューシャ/髪留め/ヘアピン/花飾り など（位置・色・形状） | |
| メイク | リップ/アイシャドウ/アイブロウ | |
| 腕・手・指 | 指輪/ネイル/爪の形状 など | |
| 特徴的な容貌 | 八重歯/泣きぼくろ/えくぼ/傷跡 など（位置明記）。顔/鼻の形状も | |
| 首から上の装飾 | イヤリング/ピアス/チョーカー/ネックレス/眼鏡/ヴェール/仮面/軍帽/ヘッドドレス など（キャラ識別の鍵・最大の特徴になりうる） | |

服飾です。服装はキャラクターの視覚的アイデンティティの5割を占めます。顔の次に画像生成の安定性を左右する要素です。服は「キャラクターの視覚的署名」であり、「赤いコートの女」「黒スーツの男」のように服装が第一印象を決定します。以下の3項目を埋めれば画像生成と執筆の両方で十分な一貫性が得られます。

| 項目 | 内容 | 画像生成タグ |
|------|------|-------------|
| 服装（上下） | トップス/ボトムス/ワンピースの種類、色（カラーコード推奨）、素材（布/革/金属など）、シルエット（タイト/ルーズ/フレア）。靴も含める | |
| 服装（特殊時） | 戦闘時/儀式時/変身後。色・シルエット・素材の変化と、追加パーツ（マント/肩当て/仮面など）を簡潔に | |
| アクセサリ | ベルト/手袋/靴下・ストッキング/マフラー/バッグ/武器ホルスター など。色と種類 | |

## C. 性格・声

C. D. E. F. の解像度を高いものにすることにより、プロットにおけるキャラクターの行動規範や、小説執筆時のセリフまわしをよりスムーズに、より自然なものにします。それは後工程の負担減とクオリティアップに繋がりますので注力してください。

| 項目 | 内容 |
|------|------|
| 性格キーワード（5つ） | 最も主要な性格特性を5つ。例: 真面目 / 好奇心旺盛 / 短気 / 優柔不断 / 献身的 |
| 表の性格 | 他人に見せる外面。社会的仮面 |
| 裏の性格 | 親しい相手にだけ見せる、または自覚していない内面 |
| 長所 | 読者に好感を持たれたいキャラクターかどうかを判断して記載する量と質を検討し、魅力的なポイントを盛り込む |
| 短所・欠点 | キャラクターの魅力は弱点にある。欠点は必ず書く |
| 口調 | 敬語/タメ口/軍人口調/古風/語尾の癖（〜だよ/〜ですわ/〜っス など） |
| 一人称 | 私/俺/僕/あたし/拙者 など。章またぎで変化する場合はバージョンごとに明記 |
| 二人称 | あなた/君/お前/貴様/〜さん など。誰に対してどの二人称か |
| 語彙の特徴 | 難しい言葉を使う/擬音が多い/比喩が詩的/無口で単語のみ など |
| 声のイメージ | 高い/低い/ハスキー/澄んだ/ボーイッシュ/艶のある など |

## D. 行動原理・内面

| 項目 | 内容 |
|------|------|
| 原体験（トラウマ） | 人格形成の根幹となった過去の出来事。いつ・何が・どう影響したか |
| 行動原理 | 意思決定時の最優先基準（「何を守りたいか」「何を恐れるか」）。例: 「他者を癒したい」/「二度と誰も失いたくない」/「自分が優位に立ちたい」 |
| 目標（外的） | 物語開始時点での外面的な目標 |
| 欲求（内的） | 自覚していない、または隠している本当の欲求 |
| 成長弧（キャラクターアーク） | 物語を通じてどのように変化するか。開始時 → 中間 → 終了時の状態 |
| 恐怖・弱点 | 物理的・精神的な恐怖対象。これを突かれると判断を誤る |
| 趣味・嗜好 | 好きな食べ物/趣味/休日の過ごし方（日常の解像度を上げる） |
| 嫌いなもの | |

## 記入例

以下は実際のプロジェクトから抜粋した高解像度記入例です。

A. 基本情報
| 項目 | 内容 |
|------|------|
| 氏名 | セシリア（Cecilia） |
| 年齢 | 19歳 |
| 身長 | 162cm |
| 体格 | B82(B)/W57/H88。細身。華奢な骨格。 |
| 所属 | 教会。聖女。 |

B. 外見（抜粋）
| 項目 | 内容 |
|------|------|
| 前髪 | 眉の上で切り揃えられたぱっつん前髪 |
| 後ろ髪 | 腰まで届く漆黒のロングストレート。背中に流す。 |
| 髪色 | 漆黒（カラーコード参考: #1a1a2e） |
| 瞳の色 | 深みのあるダークブラウン（カラーコード参考: #4a3228） |
| 瞳の形 | やや大きめの丸目。伏せると長い睫毛が影を落とす。 |
| 肌 | 陶器のように白くきめ細かい。青白いほどの透明感。 |
| 顔立ち | 卵形の輪郭、すっと通った鼻筋、小さめの唇。清楚な美人。 |

この解像度だからこそ、5章にわたる身体変化を一貫して描写でき、ComfyUI での画像生成でも安定再現できました。

## 章またぎ設定変化

同一キャラクターの章またぎ変化が大きい場合は、1バージョン1シートで上記テンプレートを再度埋めます。

```
# 例: 聖女セシリア（堕落前）→ 邪教皇女セシリア（堕落後）
# → character/01-01-セシリア_堕落前.md
# → character/01-02-セシリア_堕落後.md
```

変化前後の各項目を対比可能な形で記述します。特に画像生成に直結する以下は必須対比: 髪色・髪型・髪アクセサリ、瞳の色・瞳の形、肌の色味・質感、服装（シルエット・色・素材）、首から上の装飾、顔立ちの変化。

## 作業手順

1. proposal.md の登場人物一覧をもとに全キャラクターを列挙
2. 各キャラクターにつきテンプレート全項目をユーザと対話しながら埋める
3. 完成したシートを character/ に .md ファイルとして保存
4. 章またぎ変化があるキャラはバージョンごとに別 .md を作成
5. ユーザの承認を得てから次ステップ（世界観保存）に進む

ユーザとの対話を惜しまないでください。特に外見・性格・口調は、ユーザの頭の中にあるイメージを引き出す質問を重ねてください。あなたが「たぶんこれでいいだろう」と決めつけた箇所が、後々の執筆と画像生成のブレを生みます。
